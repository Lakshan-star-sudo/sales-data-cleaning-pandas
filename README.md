Sales Data Cleaning using Pandas
Project Overview

This mini project focuses on cleaning and preprocessing a messy sales dataset using Python Pandas in Google Colab.
Dataset

The dataset contains the following columns:

    OrderID
    CustomerName
    City
    Product
    Quantity
    UnitPrice
    OrderDate
    OrderStatus
    CustomerAge

Data Cleaning Tasks

    Handling missing values
    Detecting and handling outliers
    Correcting data types
    Standardizing text values
    Removing extra spaces
    Removing duplicate records
    Handling inconsistent date formats
    Creating a TotalAmount column

Technologies Used

    Python
    Pandas
    NumPy
    Google Colab

Project Files

    Mini_Project_Data_Cleaning.ipynb – Complete notebook
    Messy_data.csv – Original dataset
    cleaned_sales_dataset.csv – Cleaned dataset
    data_cleaning_summary.md – Cleaning summary

Output

The cleaned dataset is exported as cleaned_sales_dataset.csv.
